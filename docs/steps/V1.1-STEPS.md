# v1.1 — Gmail OAuth Authentication (starting version)

**Goal:** a script that authenticates with Gmail via OAuth and confirms it worked. No email fetching yet — that's v1.2. This version only proves the login/auth handshake works end to end.

This is a checklist, not code — write the code yourself for each part; ask for a review once it's written rather than asking for the code directly, that's the point of doing it hands-on.

---

## Part A — Google Cloud Console (external, manual, no code)

- [x] Create a Google Cloud project (e.g. `MailPilot`)
- [x] Enable the **Gmail API** for that project
- [x] Configure the **OAuth consent screen** (User type: External; add your own Gmail as a Test User)
- [x] Create an **OAuth Client ID** (Application type: **Desktop app**)
- [x] Download the credentials JSON, rename it to `credentials.json`, place it in the project root (already covered by `.gitignore`)



## Part B — Local Python environment

- [x] Create a virtual environment in the project (`python -m venv .venv`, then activate it)
- [x] Install the three Google libraries: `google-auth-oauthlib`, `google-auth-httplib2`, `google-api-python-client`
- [x] Freeze them into `requirements.txt`



## Part C — Write the authentication code (you write this)

- [ ] Create `app/adapters/gmail_adapter.py`
- [ ] Inside it, write a function `get_gmail_service()` that:
  - Defines a `SCOPES` list with just `https://www.googleapis.com/auth/gmail.readonly` (read-only — we don't need to send/delete yet)
  - Checks if `token.json` already exists on disk — if so, load credentials from it
  - If there's no token, or it's expired and can't refresh, run the OAuth flow using `credentials.json` (this is what opens the browser consent screen)
  - Saves the resulting credentials back to `token.json` so next time we skip the browser step
  - Builds and returns the Gmail API service object using those credentials
- [ ] Create `scripts/authenticate.py` — a tiny script that just calls `get_gmail_service()` and prints something like `"Authenticated successfully"` if it got a service object back



## Part D — Verify it actually works

- [ ] Run the script. Your browser should open to a Google login/consent screen.
- [ ] Log in and click Allow.
- [ ] Confirm a `token.json` file now exists in the project root.
- [ ] Confirm the console printed your success message.
- [ ] **Run the script a second time.** This time the browser should *not* open — that proves `token.json` is being reused instead of re-authenticating every run.

---

Once all four parts are checked off, v1.1 is done and we move to **v1.2**: using this authenticated service to actually list unread emails.
